Set up in three steps

No Python, no drivers to hunt for, no IP addresses to type. The first run takes about a minute; after that it is open and play.

  1. Open PocketPad Server on the PC

    Windows asks for admin once. Click Install controller driver if asked; it is built in. SmartScreen may say "unrecognised app": choose More info, then Run anyway.

  2. Install the app on your phone

    Open the APK and allow installs from your browser once. Phone and PC on the same Wi-Fi.

  3. Tap your PC and play

    Your PC shows up by name. Tap it and Windows gets an Xbox 360 controller. Up to four phones can join one PC.

Lower latency

Wi-Fi through a home router is about 5 to 15 ms. Take the router out of the path to get under 4 ms.

Phone hotspot
Turn on the phone's hotspot and connect the PC to it. The app still finds the PC on its own.
USB cable
Plug the phone in and turn on USB tethering in Android settings. Fastest and steadiest, no Wi-Fi needed.

Questions

Which games work?

Any Windows game that supports an Xbox controller, which is most of them on Steam, Epic and the Xbox app. Windows sees a standard Xbox 360 controller.

Why does Windows warn about the download?

PocketPad Server is not code-signed yet, so SmartScreen does not recognise it. Choose More info, then Run anyway. It only opens port 8080 on private networks and installs the ViGEmBus controller driver.

Why does Android ask to allow unknown apps?

The app comes from this site instead of the Play Store, so Android asks once whether your browser may install apps. A Play Store version is on the way.

My PC does not show up in the app

Check PocketPad Server is open and both devices are on the same Wi-Fi. Some routers block devices from seeing each other; type the address shown in the server window instead.

Does PocketPad collect any data?

No. No account, no analytics, no ads. Controller input goes only from your phone to your PC. Read the privacy policy.
